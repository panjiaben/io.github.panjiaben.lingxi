# 灵犀 · 本地 AI 回复助手

> **一个模块，四个平台**：微信 / 企业微信 / QQ（含群聊）/ 陌陌

把一张原生卡片接进聊天页：读懂对方发来的**文字 / 图片 / 语音**，按你设定的语气，给出**可直接使用**的话术。

全部内容只发到你**自己填的模型接口**（OpenAI 兼容），不经过任何中转服务器；无联网上报、无埋点、无广告。

---

## 它能做什么

- **卡片 / 悬浮球 / 候选浮窗**三种形态，群里也支持（默认收起，不占地）；
- **语气**：温柔、幽默、正式、撩妹高手……一键切换，逐会话可单独设；
- **角色人设**：设定角色后，话术口吻跟着角色走；
- **长期记忆**：记住聊过的事，越聊越贴合；
- **学我自己**：学习你自己的说话习惯，话术更像你本人；
- **多模态**：图片走视觉模型，语音在本地解码后转文字，再进生成管线；
- **绝不抢字**：不覆盖你正在输入的内容；群聊里默认不往输入框塞字。

## 安装

1. 需要 **root + LSPosed**（Xposed API 82 及以上）；
2. 到 [Releases](../../releases) 下载 apk 安装；
3. LSPosed 里启用「灵犀」，**作用域勾选你要用的平台**（微信 / 企业微信 / QQ / 陌陌）；
4. 打开「灵犀」App → 接口页，填一个模型接口（地址 + Key + 模型名）。

## 常见问题

- **不出话术？** 先看「灵犀」App → 接口页有没有填模型接口；
- **群里不出卡片？**「灵犀」页里的「群聊」开关默认是关的；
- **卡片不出现？** 确认 LSPosed 作用域勾了对应的 App，并重启过那个 App。
